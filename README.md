pygame-games

Games I built in 12th grade with Python and pygame. My interest in coding started the moment I realized I could make my own games with a few lines of code, and I spent that year experimenting. Each game lives in its own folder with its own README.

Game	What it is	Controls
When It Rains	Dodge falling raindrops as a cat	Left / Right arrows
Luna Dress-Up	A dress-up game with hand-drawn art	Mouse
Snake	Classic snake on a small wrap-around grid	W A S D
Run a game

Requires Python 3.9+.

bash
git clone https://github.com/debbie3464/pygame-games.git
cd pygame-games
pip install -r requirements.txt
python when-it-rains/main.py

Swap when-it-rains for luna-dress-up or snake to run the others. Each game can be started from any folder.

About

These were written while I was still learning, so the code is simple and in places repetitive. Luna Dress-Up was my first complete Python project, and I drew all of its art myself. Each README lists known limitations and what I would improve.
